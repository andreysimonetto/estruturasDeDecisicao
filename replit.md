# Java Project

## Overview

A simple Java project using GraalVM 22.3 (OpenJDK 19). The entry point is `Main.java`.

## Structure

- `Main.java` — main entry point (`public class Main` with `main` method)

## Running

The workflow **main.java** compiles and runs the project:

```bash
javac Main.java && java Main
```

## User Preferences

- Entry point file: `Main.java`
- Workflow name: `main.java`
